# Каузальный анализ влияния ключевой ставки ЦБ на кредитный и депозитный рынки России

Портфолио-проект, исследующий как изменения ключевой ставки Банка России передаются на ипотечный рынок и рынок вкладов физлиц с использованием метода Local Projections (Jordà 2005).

---

## Исследовательские вопросы

1. **Ипотечный рынок:** снижает ли повышение ключевой ставки объём выдачи ипотечных кредитов, и на каком лаге эффект максимален?
2. **Рынок вкладов:** увеличивает ли повышение ставки объём вкладов физлиц — перекладывают ли люди деньги с текущих счетов на срочные депозиты?
3. **Асимметрия**: симметричен ли эффект — одинаково ли реагирует рынок на повышение и понижение ставки на одну и ту же величину?

---

## Метод

**Local Projections** (Jordà 2005) с лаг-аугментацией (Montiel Olea & Plagborg-Møller 2021).

Для каждого горизонта h = 0, 1, ..., H оценивается отдельная OLS-регрессия:

```
y_{t+h} = α + β·key_rate_t + γ·controls_t + ε_t
```

Последовательность коэффициентов β по горизонтам образует функцию импульсного отклика. Используются робастные стандартные ошибки HC3.

Для каждого исхода сравниваются две спецификации:
- **Наивная:** без лаг-аугментации и тренда — используется для демонстрации ложной значимости из-за персистентности
- **Финальная:** с `key_rate_lag1`, `y_lag1` и `trend` — основная спецификация

Все результаты интерпретируются как **условные корреляции**, а не строгие причинно-следственные эффекты. Ключевая ставка эндогенна: ЦБ повышает её в ответ на инфляцию, которая сама влияет на поведение заёмщиков и вкладчиков. Идентификация без инструментальных переменных невозможна.


Для вопроса 3 используется расширенная LP с взаимодействиями:

```
y_{t+h} = α + β₁·key_rate + β₂·hike + β₃·cut
        + β_xh·(key_rate × hike) + β_xc·(key_rate × cut) + γ·controls + ε
```
Наблюдения разбиты на три группы: **паузы** (ставка не изменилась, база, 93 месяца), **повышения** (hike=1, 23 месяца), **понижения** (cut=1, 39 месяцев). Прямой тест асимметрии — линейная гипотеза β_xh − β_xc = 0.

## Основные результаты

### Вопрос 1 — Ипотечный рынок

На **полной выборке 2019–2025** ключевая ставка не оказывает статистически значимого эффекта на объём ипотеки. Программа льготной ипотеки (апрель 2020 – июль 2023) экранировала рынок от трансмиссии денежно-кредитной политики — заёмщики получали ипотеку по субсидированным ставкам 6–7% даже когда ключевая ставка была 20%.

На **подвыборке без субсидий** (52 наблюдения) эффект ставки на объём ипотеки **не значим ни на одном горизонте**.
**Четыре причины отсутствия идентификации:**
  1. **Малая выборка и разрыв:** 52 наблюдения в двух кусках (14 и 38),
     между ними 3 года. Лаги переносят значения через разрыв.
  2. **Коллинеарность `key_rate` и `gap_dummy`:** VIF = 50.9 и 14.9 —
     ставка почти детерминирована временной частью данных.
  3. **Эндогенность ставки:** pre-trend check показал, что лид значим
     на h=1 (p=0.014). Рынок реагирует на будущее изменение ставки,
     значит ставка эндогенна.
  4. **Ложная значимость в наивной модели** — показать важность лаг-аугументации.

**Главный вывод:** программа льготной ипотеки отключила ипотечный рынок от процентного канала денежно-кредитной политики.

### Вопрос 2 — Рынок вкладов

Механизм трансмиссии подтверждён в три шага:

**Шаг 1 — Ключевая ставка → ставки по вкладам.** Краткосрочная ставка реагирует через 2–3 месяца с передачей близкой к полной (β ≈ 1.0). Долгосрочная ставка реагирует медленнее — β достигает 0.9 только к h=9.

**Шаг 2 — Ставки по вкладам → перекладывание средств.** Срочные депозиты растут начиная с h=2, эффект монотонно нарастает до h=15 без затухания (около 942 млрд руб. на h=15). Текущие счета падают на h=2–7 с пиком на h=4 (−255 млрд руб.) — люди переносят деньги на срочные вклады.

**Шаг 3 — Итоговый эффект на общий объём вкладов.** Значим на h=6–7 и h=11–15. Разница между ростом срочных депозитов и падением текущих счетов (~225 млрд руб. на h=4) указывает на чистый приток новых средств в банковскую систему сверх простого перекладывания.


### Вопрос 3 — Асимметрия эффекта ключевой ставки

Асимметрия **не подтверждается** на уровне значимости 5%.

**Общий объём вкладов:** при повышении ставки реакция значима на h=6–7, при понижении — незначима нигде. Тест асимметрии значим **только на h=4** (200 млрд руб.) — единственная точка, устойчивого паттерна нет.

**Срочные депозиты:** асимметрии нет — рынок **симметричен**. Оба направления дают значимый приток сопоставимой величины: при повышении с h=2, при понижении — на h=3–7. Ключевая находка — при понижении тоже есть приток: люди фиксируют высокую ставку пока банки не снизили депозитные ставки («эффект фиксации»).

**Текущие счета:** реакция слабая и несистемная. Значимая асимметрия только на h=15 (311 млрд руб.) — при понижении счета падают сильнее. Вероятно отражает экономический контекст посткризисных периодов, а не поведенческую асимметрию.


## Ограничения

- **Эндогенность ставки:** ЦБ повышает ставку в ответ на инфляцию; инфляция сама влияет на поведение заёмщиков и вкладчиков. Без инструментальных переменных строгая каузальная идентификация невозможна.
- **Отсутствие контроля за экономическим циклом в вопросе 2:** М2 исключён так как `total_funds_of_ind` является его компонентом. Помесячные данные по ВВП или промышленному производству недоступны.
- **Нет контроля по доходам и ценам на жильё:** Росстат публикует эти данные только поквартально.
- **Малая выборка (вопрос 1):** только 52 наблюдения после исключения периода субсидий, разбитых на два отрезка с большим промежутком между.
- **Остаточное субсидирование после июля 2023:** семейная ипотека и IT-ипотека продолжились в меньшем масштабе и не контролируются.
- **Асимметрия протестирована только для рынка вкладов:** для ипотечного рынка тест на асимметрию не проводился по трём причинам. Во-первых, после исключения периода субсидий остаётся только 52 наблюдения разбитых на два несвязных отрезка (февраль 2019 — март 2020 и август 2023 — декабрь 2025), где повышения и понижения ставки почти полностью разнесены по периодам — разделить эффект направления от эффекта периода невозможно. Во-вторых, высокая коллинеарность ключевой ставки и дамми периода (VIF > 50) делает оценки взаимодействий ненадёжными. В-третьих, на полной выборке 2019–2025 основной эффект ставки уже незначим из-за субсидий — тестировать асимметрию поверх нулевого эффекта бессмысленно.
- **Асимметрия (вопрос 3):** результаты интерпретируются **описательно**. Повышений в выборке только 23 из 156 наблюдений — тесты для группы повышений имеют низкую мощность и широкие доверительные интервалы. Периоды повышений и понижений различаются по экономическому контексту: разделить поведенческую асимметрию от контекстуальной без инструментальных переменных невозможно.
